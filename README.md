# Seasonal Agriculture Performance Analysis

## Project Overview

This project analyzes agricultural performance across different seasons using data analytics techniques.

The analysis focuses on seasonal variations in crop yield, production, environmental conditions, resource usage, irrigation methods, disease/pest risk and economic performance.

## Objectives

- Analyze agricultural performance across seasons
- Identify seasonal patterns and trends
- Compare crop performance
- Analyze resource utilization
- Study relationships between environmental conditions and agricultural outcomes
- Analyze economic performance
- Generate data-driven insights and recommendations

## Dataset

The dataset contains 4000 records and 28 variables related to:

- Farm details
- Location
- Crop
- Season
- Environmental conditions
- Soil characteristics
- Farming practices
- Yield and production
- Resource usage
- Cost, revenue and profit
- Disease and pest risk

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Findings

- Kharif recorded the highest average yield of approximately 5.63 tonnes/ha.
- Kharif recorded the highest total production.
- Kharif recorded the highest average profit.
- Drip irrigation was associated with the highest average yield.
- Water efficiency showed a strong positive relationship with crop yield.
- Zaid recorded negative average profit.
- Kharif recorded the highest average disease and pest risk.
